# ChunapTool v0.1.0 実装計画・報告

## 事前確認

- 移行先は存在せず、親KotorinToysの作業ツリーはクリーン。親は既存の`feature/full-refactoring`を維持し、子は`main`で独立管理する。
- 移行元のChunapToolは位置・サイズ調整専用。WGCには未完成の仮定があり、PrintWindowへフォールバックする構成。
- C#版はWindows FormsとWin32/DWMを直接使用し、外部NuGet・Python・OpenCV・FFmpegの実行時依存を持たせない。
- 座標の正本はDWMの見える矩形。移動時は不可視枠を補正する。UndoではWINDOWPLACEMENTを保存し、作業領域座標と画面座標の混在を避ける。

## フェーズ

- [ ] 1: 抽出範囲・共有型・独立Git・資料を作成し、差分とリンクを検査してコミット。
- [ ] 2: ウィンドウ操作、制約計算、Undo、WinForms画面、DWMプレビューを実装。ビルド・単体検証後コミット。
- [ ] 3: 専用テストウィンドウで実機検証、最終UI確認、手順と結果を更新してコミット。親の紹介とGit参照を記録。

## 分担

- 親: 仕様解釈、共有型、画面、統合、文書、検証・コミット。
- ウィンドウ担当: Win32操作、DWMプレビュー。変更範囲はNative/。
- ロジック担当: 制約計算、履歴、単体検証。変更範囲はCore/の共有型以外とtests/。

## 検証計画

- 作業領域の負座標、最小サイズ、大きすぎる要求、Undo上限、対象切替、ドラッグ中の履歴抑制、失敗時の履歴維持を検証する。
- 専用WinFormsテスト画面のみを操作し、列挙、移動、サイズ変更、最大化、復元、DWMサムネイル、対象終了を検証する。
- 最終UI確認では実画面を観測し、検索・手動適用・Undo・同期・最大化・プレビューを操作する。録画と生ログはこの版のlogs/へ保存する。

## 技術参照
