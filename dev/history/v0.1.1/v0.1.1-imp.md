# ChunapTool v0.1.1 実装計画・報告

対応要求: [v0.1.1要求](v0.1.1-req.md)

作成日: 2026-10-15 / 状態: 実装中 / ブランチ: 子リポジトリのmain

## 0. 事前確認

- 子リポジトリはクリーン。親KotorinToysでは他ツールの開発差分があるため、今回の実装・コミットはChunapTool配下に限定する。
- 現行の同期チェックは入力反映タイマー、適用ボタンの有効状態、自動読み取りの強制更新を一つの設定で扱う。定期読み取り自体は同期チェックと独立して動いている。
- 最大化ボタンのCheckedは実状態と同期するがTextは固定。FlowLayoutPanelは高さの異なるボタンとチェックボックスを上端寄せし、NumericUpDownはDock=Fillでセル上側へ配置されている。
- 今回は実装依頼と版番号が明示されている。配布、公開、インストールの更新は対象外。

## 1. フェーズとコミット単位

- [ ] 1: v0.1.1の要求・計画を作成し、リンク・差分を検査してコミット。
- [ ] 2: R1〜R6の画面・設定分離・版更新と関連回帰テストを実装。ビルド、単体・不可視UI検証後コミット。
- [ ] 3: 利用手順と版別報告を更新し、リンク・差分を検査してコミット。

## 2. 実装方針

| 要求 | 実装 |
|---|---|
| R1 | MainFormの状態表示に最大化／通常化の文字列切替を集約。外部最大化とUndoにも追従 |
| R2 | autoReadとautoApplyを別のCheckBoxとして導入。定期的な座標表示更新と入力反映タイマーを各設定で制御 |
| R3 | Applyは編集可能かつautoApply=OFFで有効。Enterでの手動適用を廃止。OFFへの切替で待機中タイマーを停止。画面外設定変更と定期補正もautoApplyで制御 |
| R4 | 操作行を最大化、自動読み取り、自動反映、適用、画面外可、戻すの順とする |
| R5 | 操作行をTableLayoutPanelの1行とし各要素を縦中央へ揃える。座標欄はDockを外し左右Anchorで横幅を追従しつつセル縦中央へ配置 |
| R6 | アプリ・テストのプロジェクト、tool.json、現在版の目録を0.1.1へ更新 |

## 3. 検証計画

- 既存Core検証と不可視UI回帰を継続する。
- 二つのチェックの4組合せで、外部移動の表示と入力反映を独立検証する。
- 自動反映OFFでEnter、画面外設定、定期補正が位置変更を送らず、適用ボタンだけが編集値を送ることを検証する。
- 最大化／通常化の外部状態追従・操作・Undoを確認する。
- 最小ウィンドウ寸法で全操作が重ならず、操作行の上下中心、座標ラベルと数値欄の上下中心、適用と画面外可の順序を実測する。
- 生ログはこの版のlogs/<実行識別子>/へ保存する。実描画・実マウス操作は不可視回帰の証拠に含めない。
