# ChunapTool v0.2.0 要求

依頼日: 2026-10-31

競合製品（Sizer、PowerToys、DisplayFusion、Rectangle/Magnet など）を参考にした機能追加の候補14件を、すべて実施する。全機能をコマンドラインから呼び出せるようにし、テストもコマンドラインで行う。設計は[v0.2.0設計書](v0.2.0-design.md)を参照。

## 進捗

P1（基盤: CLIの骨格と既存機能の一部、CLI検証）を実装済み。詳細は[v0.2.0実装計画・報告](v0.2.0-imp.md)。

## 未実装

### 機能

- R1: サイズのプリセット。1920×1080、1280×720などを既定で持ち、利用者が追加・削除・並べ替えできる。選ぶだけで対象へ反映する。
- R2: 位置・サイズの基準を「見える枠」と「クライアント領域（中身）」で切り替えられる。
- R3: 縦横比を固定してW/Hを編集できる。
- R4: 対象をワンクリックで定位置へ配置する（中央、左右上下の半分、四隅、作業領域いっぱい）。
- R5: 対象ウィンドウを最前面に固定・解除できる（ChunapTool自身の「最前面」とは別）。
- R6: 選んだ対象を枠で一時的にハイライトし、取り違えを防ぐ。
- R7: 設定を保存し、次回起動時に復元する（自動読み取り、自動反映、画面外可、最前面、基準、縦横比固定、プリセット、配置プロファイル、ショートカット）。
- R8: モニターを指定して移動できる（次・前・番号指定）。座標をモニターの作業領域を基準に表示・入力できる。
- R9: 全体ショートカット（ホットキー）でプリセット適用、定位置配置、戻す・やり直す、最前面切替、ハイライトを実行できる。
- R10: やり直し（Redo）。
- R11: 外部から適用できる（コマンドラインと管理pipe）。
- R12: 複数ウィンドウの配置プロファイルを保存し、まとめて並べ直す。アプリの起動は行わない。
- R13: 作業領域を格子に分けたセルへ配置する（グリッド配置）。
- R14: 対象ウィンドウの透明度を変更・解除できる。

### コマンドライン

- C1: 既存機能（候補の一覧・検索、ドラッグ選択相当の座標指定、状態取得、位置・サイズ変更、最大化・通常化、画面内補正、サムネイル撮影、プレビュー、管理の状態確認・表示・停止）と、R1〜R14のすべてをコマンドラインから呼び出せる。
- C2: 機械が読める出力（JSON）と、成功・失敗を区別できる終了コードを持つ。
- C3: 対象が一意に決まらない場合は操作しない。変更せずに結果だけを計算する試行（dry-run）を持つ。

### テスト

- T1: 新機能のテストはコマンドラインの呼び出し（終了コードとJSON出力）で行う。
- T2: テストが操作するウィンドウは、テスト自身が起動した確認用ウィンドウと、`--passive`で起動したChunapToolに限る。実機のマウス・キーボード入力は使わない。
- T3: ウィンドウを使わないテストはGitHub Actionsでも実行する。

## 実装済

- なし。

## 操作の定義

- 見える枠: DWMが描画する外形（現行のX/Y/W/H）。透明なリサイズ枠を含まない。
- クライアント領域: タイトルバーと枠を除いた中身。録画やスクリーンショットで中身の大きさを揃える用途で使う。
- 定位置・グリッド配置はChunapToolが位置とサイズを計算して反映するもので、Windowsのスナップ状態にはしない。
- 前面ウィンドウ: ショートカット実行時点でキーボード入力を受けているウィンドウ。ChunapTool自身は対象外。

## 継続する指示

- 他の開発の画面操作を優先する。テストは自分で起動したウィンドウだけを操作し、実機入力を使わない。
- コミットは日本語、フェーズごとにビルドと関連テストを通してからコミットする。
