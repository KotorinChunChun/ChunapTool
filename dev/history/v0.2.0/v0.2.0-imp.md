## 2. P1の実装

| 項目 | 実装 |
|---|---|
| 操作層 | `Operations/WindowOperations.cs`。`MainForm.MutateAsync`の反映確認（70ms間隔、2回安定で確定、期限で打切り）を`WaitForAsync`として切り出し、GUIとCLIで共有する。完了条件（位置・サイズ、最大化、復元）も同じ関数を使う。GUIの画面を閉じた場合の打切りは、`OperationCanceledException`で扱う |
| 対象指定 | `Core/TargetSelector.cs`（純粋関数）。`WindowEntry`にクラス名、`IWindowService`に前面ウィンドウの取得を追加。ChunapTool.exeとchunap.exeは除外する |
| CLI | `src/ChunapTool.Cli`（`chunap.exe`、外部パッケージなし）。`list`、`pick`、`get`、`set`、`maximize`、`unmaximize`、`constrain`、`restore`、`version`、`help`。起動時にPer-Monitor V2にして、GUIと同じ物理ピクセルで扱う |
| 引数の安全 | すべての引数を読み取って検査してから、対象の解決と変更を行う。綴り誤りのオプション（例: `--wdith`）や、値の書き忘れ（`--pid --json`）で対象を動かさない |
| 出力 | `--json`は既定のエンコーダーで非ASCIIを`\uXXXX`にし、コンソールのコードページに依存させない。変更系は`before`・`requested`・`after`・`warnings`を返す。`get`の`state`と変更系の`before`は、`restore --from`でそのまま読める |
| `--instance` | `ChunapTool.exe --instance <ID>`で、ミューテックス名と管理pipe名に`<ID>`を付ける。省略時は従来と同じ名前（KotorinToys本体との互換） |
| 確認用ウィンドウ | `--fixture`に`--title`、`--client`、`--position`、`--min`、`--topmost`、`--hung`（UIスレッドを止める）、`--locked`（移動・サイズ変更を無視）を追加 |
| CLI検証 | `ChunapTool.Tests.exe --cli`（ウィンドウを変更しない）と`--cli-native`（確認用ウィンドウと検証用GUIだけを操作）。`test.ps1 -Cli`・`-CliNative`。結果は終了コードとJSONで判定し、位置・最大化はWin32で直接読んだ値とも突き合わせる |
| CI | `-Cli`をGitHub Actionsに追加。`-CliNative`はローカルで実行する |

設計からの変更:

- 設計書2.2節の`WindowOperations`の公開メソッドは、P1で使う`SetBoundsAsync`、`SetMaximizedAsync`、`RestoreAsync`と、共通の`WaitForAsync`・完了条件から作った。GUIは、履歴と画面の更新を`MainForm`に残したまま、反映確認と完了条件を共有する。その他の操作は各フェーズで追加する。
- `--instance`は設計ではP5の項目だが、検証用GUIを利用者のGUIと分離する土台としてP1で実装した。
