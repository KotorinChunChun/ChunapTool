# KotorinToys管理連携

ユーザー専用名前付きパイプで状態確認・既存画面の表示・正常停止に対応します。既存の設定保存・履歴・動画は移動しません。

- 通常起動は画面表示、`--startup`は画面非表示の常駐です。本体から「起動設定を開く」で表示できます。
- 二重起動は既存の同一EXEを前面化します。PIDと利用者を検証します。
- 1要求は改行までの4096文字以内です。超える要求、壊れたJSON、整数でない`expectedPid`は拒否し、受付は継続します。接続後、要求の読取りから応答の書込みまでを2秒で打ち切ります。
- 録画・書き出し・ウィンドウ操作などの処理中、およびモーダル画面表示中は管理停止を拒否します。操作完了後に再実行してください。
- テスト時は`--settings-dir <専用フォルダー>`を使えます（ChunapToolは保存設定なし）。CapchunScreenの`--passive`はテスト用にホットキーを取得しません。ChunapToolの`--passive`は既存の不可視テストモードです。
- GitHub Releasesの既存ポータブル版を保持し、0.1.2から本体対応Inno形式で正式導入・更新・削除に対応します。固定製品識別と製品別配布台帳を使います。ChunapToolは設定・Undo履歴を保存しないため、更新・削除で引き継ぐ利用者データはありません。[導入ガイド](install.md)を参照してください。
- キー一覧の本体連携は未実装のため、空の予約ファイルのみ置きます。実操作は製品の利用ガイドを参照してください。
