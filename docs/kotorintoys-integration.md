# KotorinToys管理連携

ユーザー専用名前付きパイプで状態確認・既存画面の表示・正常停止に対応します。既存の設定保存・履歴・動画は移動しません。

- 通常起動では画面を表示し、`--startup`で起動すると画面を表示せずに常駐します。本体の「起動設定を開く」で画面を表示できます。
- 二重起動は既存の同一EXEを前面化します。PIDと利用者を検証します。別の場所のEXE（ポータブル版とインストール版など）が起動中の場合や応答がない場合は前面化せず、手動起動では理由と両方の場所をメッセージで示します。`--startup`では表示しません。
- 1件の要求は改行までの4096文字以内です。この上限を超える要求、壊れたJSON、整数でない`expectedPid`は拒否しますが、次の要求は引き続き受け付けます。接続後は要求の読取りから応答の書込みまでを2秒で打ち切ります。
- 録画・書き出し・ウィンドウ操作などの処理中、およびモーダル画面表示中は管理停止を拒否します。操作完了後に再実行してください。
- テスト時は`--settings-dir <専用フォルダー>`を使えます。ChunapToolはv0.1.3から設定を保存するため、検証用の起動では専用フォルダーを指定してください。`chunap.exe`も同じオプションを受け付けます。CapchunScreenはテスト用の`--passive`で起動するとホットキーを取得しません。ChunapToolの`--passive`は既存の不可視テストモードです。
- GitHub Releasesの既存ポータブル版を保持し、0.1.2から本体対応Inno形式で正式導入・更新・削除に対応します。固定製品識別と製品別配布台帳を使います。v0.1.2は設定・Undo履歴を保存しません。v0.1.3からは設定を`%LOCALAPPDATA%\KotorinToys\ChunapTool\`へ保存します。導入先の外のため、更新で失われません。[導入ガイド](install.md)を参照してください。
- キー一覧はまだ本体と連携していないため、空の予約ファイルだけを置きます。操作方法は製品の利用ガイドを参照してください。
